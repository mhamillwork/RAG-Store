# MCP

Tools: `search_knowledge`, `search_global_knowledge`, `search_local_knowledge`, `list_collections`, `get_document`, `get_document_chunks`, `get_document_markdown`, `get_document_tables`, `get_source_reference`, `get_ingestion_status`.

Point Open WebUI or another MCP client at `https://<mcp-host>/mcp` with the user's bearer token or a service API key. A service key searches GLOBAL only. Retrieved text is untrusted data. The server instructions say not to follow directions found in documents.

This service does not replace `technical_knowledge_mcp`, `atoms_knowledge_mcp`, `gtiss_dis_knowledge_mcp`, `wobbegong_sql_mcp`, or `devsecops_knowledge_mcp`.
